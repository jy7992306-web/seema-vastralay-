SEEMA VASTRAALAY WEBSITE

Files:
- index.html: Main website page
- style.css: Design and responsive layout
- script.js: Category filters and mobile menu

Before publishing:
1. Replace the example product prices with your actual prices.
2. Replace the address, phone number, and shop hours in index.html.
3. You can replace image URLs in index.html and style.css with your own product photos.
4. Images and Google Fonts need internet access because they are loaded from external websites.

GitHub Pages (mobile):
1. Sign in at https://github.com/
2. Create a PUBLIC repository named seema-vastraalay
3. Upload index.html, style.css, and script.js into the repository root (not inside another folder).
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait a few minutes. Your URL will be https://YOUR-USERNAME.github.io/seema-vastraalay/
